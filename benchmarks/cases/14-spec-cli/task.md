从零写一个命令行小工具 `wc-lite.mjs`（Node ESM，只允许用内置模块，不引入第三方依赖）。

用法：

```
node wc-lite.mjs <file> [--lines]
```

行为要求（请严格按此实现，验证脚本会逐条比对）：

1. 默认输出一行：`<行数> <单词数> <字节数>`，三个数字之间用**单个空格**分隔，行尾有一个换行。
   - 行数 = 文件中换行符 `\n` 的个数
   - 单词数 = 按空白字符（空格、制表符、换行）切分后的非空片段个数
   - 字节数 = 文件内容的字节长度（UTF-8 编码）
2. 带 `--lines` 时只输出行数（一个数字 + 换行），例：`node wc-lite.mjs sample.txt --lines`
3. 文件不存在时：向 **stderr** 打印 `error: <文件名> not found`，进程退出码为 1，stdout 不输出任何内容。
4. 空文件：默认输出 `0 0 0`。

约束：不要修改 `sample.txt`、`empty.txt` 等测试数据文件，也不要新增其它文件（只创建 `wc-lite.mjs`）。
